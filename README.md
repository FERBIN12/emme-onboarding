# Emme Onboarding

TOA Healthcare Hackathon 2026-07-25 — Track 2 (Emme).

Member-facing insurance intake flow: upload an SBC/EOB to auto-fill plan details, or enter them manually with plain-language guidance. Autosaves progress, completable in under 3 minutes on mobile.

## Structure

- `backend/` — FastAPI service: session storage, autosave, document extraction, structured export
- `frontend/` — member-facing intake flow

## Team

4-person team, Red Hat Fort Point, Boston.
